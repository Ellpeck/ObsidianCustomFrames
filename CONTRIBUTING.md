# Contributing

Hi, thanks for contributing to Custom Frames!

Before reporting an issue or suggesting a new feature, please check the [README](README.md)'s [Roadmap](README.md#%EF%B8%8F-roadmap) and [Known Issues](https://github.com/Ellpeck/ObsidianCustomFrames/blob/master/README.md#%EF%B8%8F-known-issues) sections. If your issue or suggestion is already listed there, you don't need to report it here.

When reporting an issue, please be sure to check and report on whether the same issue happens when using the [web viewer core plugin](https://help.obsidian.md/plugins/web-viewer), as they use very similar technology.

Thanks! ❤️

## AI-Generated Content Policy

This project does not accept content created with generative artificial intelligence (GenAI) or large language models (LLMs). All contributions created entirely or substantially with GenAI or LLMs will be removed. This includes code, documentation, and asset contributions, as well as issue and pull request descriptions.

GenAI may only be used for the purpose of understanding the codebase and its documentation or for user-reviewed debugging assistance, provided that the results are thoroughly reviewed and any suggested code is manually implemented.
